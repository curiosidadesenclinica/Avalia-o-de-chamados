# Avaliação de Chamados

Aplicativo Cordova da Engenharia Clínica.

## Estrutura
- `www/index.html` — aplicativo
- `www/img/` — ícone e tela de abertura
- `resources/` — recursos Android
- `config.xml` — configuração Cordova
- `package.json` — plataforma e plugins
- `.github/workflows/gerar-apk.yml` — geração automática

O APK gerado é salvo automaticamente em:
`saida/Avaliacao_de_Chamados.apk`
